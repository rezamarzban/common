For the modified scenario — a 70 cm wire antenna in a 1 V/m field at 100 MHz, with either a 2N2222A or BC547 BJT — the calculations are explained below, followed by Python code and SPICE netlists for each transistor.

Antenna and signal
- Effective height of a short vertical monopole is half its physical length. For a 70 cm wire, h_eff = 0.70 m / 2 = 0.35 m.
- Open-circuit voltage RMS: V_oc = E * h_eff = 1 V/m * 0.35 m = 0.35 V = 350 mV RMS.
- The antenna behaves as a small capacitor. For a 70 cm wire, the capacitance is larger than for 30 cm; we estimate C_ant ≈ 5 pF.
- The antenna impedance at 100 MHz is purely capacitive: Z_ant = 1/(j*2*pi*f*C_ant) ≈ -j318 ohm.

DC bias circuit (feedback biasing)
- Supply V_CC = 9 V. Choose quiescent collector current I_C = 1 mA and collector-emitter voltage V_CE = 4.5 V for maximum swing.
- Collector resistor R_C = (V_CC - V_CE)/I_C = (9 - 4.5)/0.001 = 4500 ohm, use 4.7k standard.
- The base is biased via a resistor R_B from collector to base. Emitter is grounded.
- Base current I_B = I_C / h_FE, where h_FE is the DC current gain. For 2N2222A we use h_FE = 150; for BC547 we use h_FE = 200.
- Voltage across R_B: V_RB = V_CE - V_BE, with V_BE = 0.7 V.
- R_B = V_RB / I_B. For 2N2222A: I_B = 1 mA / 150 = 6.67 µA; R_B = (4.5 - 0.7)/6.67e-6 = 570k (use 560k). For BC547: I_B = 1 mA / 200 = 5 µA; R_B = 3.8/5e-6 = 760k (use 750k).

Small-signal analysis at 100 MHz
- The BJT’s quiescent transconductance g_m = I_C / V_T = 0.001 / 0.026 ≈ 38.5 mS, where V_T = 26 mV at room temperature.
- Low-frequency voltage gain (without external load) A_v_lf = -g_m * R_C. With R_C=4.7k, A_v_lf ≈ -181.
- At 100 MHz, the current gain falls. The transition frequency f_T is 300 MHz for 2N2222A and 150 MHz for BC547. The small-signal base input resistance at high frequency is r_pi = beta_ac / g_m, where beta_ac = f_T / f (for f >> f_beta). For 2N2222A: beta_ac = 300/100 = 3 → r_pi = 3 / 0.0385 ≈ 78 ohm. For BC547: beta_ac = 150/100 = 1.5 → r_pi = 1.5 / 0.0385 ≈ 39 ohm.
- The internal base-emitter capacitance C_pi includes diffusion and junction capacitance. We approximate C_pi_est as 8 pF for both.
- The collector-base capacitance (C_mu, also called C_obo) is about 8 pF for 2N2222A and 4.5 pF for BC547.
- Because of the Miller effect, the input capacitance is increased: C_miller = C_mu * (1 + |A_v_lf|). For 2N2222A: C_miller ≈ 8 pF * (1+181) ≈ 1456 pF. For BC547: C_miller ≈ 4.5 pF * 182 ≈ 819 pF. These are huge and dominate the input capacitance.
- Total input capacitance C_in_total = C_pi_est + C_miller, giving about 1464 pF for 2N2222A and 827 pF for BC547.
- The small-signal input impedance Z_in is r_pi in parallel with the capacitive reactance of C_in_total. At 100 MHz, the capacitive reactance is much smaller than r_pi, so Z_in is approximately 1/(j*omega*C_in_total), with a magnitude of about 1.09 ohm for 2N2222A and 1.92 ohm for BC547.
- The antenna sees this very low input impedance in series with its own reactance (318 ohm). The voltage division factor is approximately |Z_in| / sqrt( |Z_ant|^2 + |Z_in|^2 ), which is about 0.0034 for 2N2222A and 0.0060 for BC547.
- Thus the base voltage V_base = V_oc * division_factor. For 2N2222A: V_base ≈ 350 mV * 0.0034 = 1.2 mV RMS. For BC547: V_base ≈ 350 mV * 0.0060 = 2.1 mV RMS.
- The output voltage is then v_out = |A_v_lf| * V_base, giving about 217 mV RMS for 2N2222A and 380 mV RMS for BC547. However, these numbers are optimistic because the low-frequency gain does not hold at 100 MHz; the output collector node also has capacitance that shunts R_C, reducing the actual gain. The calculation still shows that the BC547 yields a larger output mainly because its smaller C_mu produces less Miller multiplication.

Python code for 2N2222A

```python
import cmath, math

f = 100e6
omega = 2*math.pi*f
V_CC = 9.0
I_C = 1e-3
V_CE_target = 4.5
R_C = (V_CC - V_CE_target) / I_C
R_C_std = 4700.0
V_CE = V_CC - I_C * R_C_std
h_FE_dc = 150.0
I_B = I_C / h_FE_dc
V_BE = 0.7
V_RB = V_CE - V_BE
R_B = V_RB / I_B
R_B_std = 560e3

g_m = I_C / 0.026
f_T = 300e6
beta_ac = f_T / f
r_pi = beta_ac / g_m
A_v_lf = -g_m * R_C_std

E = 1.0
L_wire = 0.70
h_eff = L_wire / 2
V_oc = E * h_eff

C_ant = 5e-12
Z_ant = 1/(1j * omega * C_ant)

C_mu = 8e-12
C_pi_est = 8e-12
C_miller = C_mu * (1 + abs(A_v_lf))
C_in_total = C_pi_est + C_miller

Z_in = 1/(1/r_pi + 1j*omega*C_in_total)
divider = Z_in / (Z_ant + Z_in)
V_base = V_oc * divider
v_out = abs(A_v_lf) * abs(V_base)

print("2N2222A BJT Amplifier at 100 MHz, 1 V/m, 70 cm wire")
print("V_CC =", V_CC, "V, R_C =", R_C_std, "ohm, V_CE =", round(V_CE,2), "V")
print("I_C =", I_C*1000, "mA, DC hFE =", h_FE_dc, ", I_B =", round(I_B*1e6,2), "uA")
print("R_B (standard) =", R_B_std/1e3, "kOhm")
print("g_m =", round(g_m*1000,2), "mS")
print("f_T =", f_T/1e6, "MHz, beta_ac at 100MHz =", beta_ac)
print("r_pi =", round(r_pi,1), "ohm")
print("Low-freq A_v =", round(A_v_lf,2))
print("C_mu =", C_mu*1e12, "pF, C_pi_est =", C_pi_est*1e12, "pF")
print("C_miller =", round(C_miller*1e12,1), "pF")
print("Total C_in =", round(C_in_total*1e12,1), "pF")
print("Antenna: h_eff =", h_eff, "m, V_oc =", round(V_oc*1000,1), "mV RMS")
print("Z_ant magnitude =", round(abs(Z_ant),1), "ohm")
print("Z_in magnitude =", round(abs(Z_in),3), "ohm")
print("V_base =", round(abs(V_base)*1000,2), "mV RMS")
print("v_out (using low-freq gain) =", round(v_out*1000,1), "mV RMS")
print("Note: Actual output may be lower due to collector capacitance loading at 100 MHz.")
```

V_ant in 0 AC 0.35
C_ant in base 5p
R_C cc collector 4.7k
R_B collector base 560k
V_CC cc 0 9
Q1 collector base 0 2N2222A
.MODEL 2N2222A NPN (IS=14.34f BF=150 NF=1 VAF=50 IKF=0.1 ISE=14.34f NE=2

.END
