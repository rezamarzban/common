Equations used throughout the conversation

Antenna and signal reception
- lambda = c / f
- h_eff = L / 2  (effective height of short monopole)
- V_oc = E * h_eff  (open-circuit voltage RMS)
- V_peak = V_oc * sqrt(2)
- C_ant ≈ 3 pF (for 30cm wire)
- V_gate = V_oc * C_ant / (C_ant + C_iss)  (capacitive voltage divider)
- V_oc_loop = 2 * pi * f * N * A * B  (loop antenna EMF)
- B = mu_0 * H,  H = E / 377  (free-space field conversion)
- he_loop = (2 * pi * f * N * A) / c  (effective height of loop)
- V_cap = V_oc * Q  (resonant voltage step-up in LC tank)
- V_out = V_source * Z_load / (Z_source + Z_load)  (general voltage division)

DC biasing (MOSFET and JFET)
- V_D = V_DD - I_D * R_D  (drain voltage)
- I_D = I_DSS  (JFET at V_GS=0)
- R_D = V_DD / (2 * I_DSS)  (centered drain bias for JFET)
- |A_v| = V_DD / |V_P|  (gain with centered bias)
- V_GS = V_D  (feedback bias with gate-drain resistor)
- I_D = (k_n/2) * (V_GS - V_th)^2  (enhancement MOSFET saturation)
- V_ov = V_GS - V_th  (overdrive voltage)
- I_B = (V_CE - V_BE) / R_B  (BJT feedback bias)
- V_CE = V_CC - I_C * R_C  (BJT collector voltage)

Small-signal parameters and gain
- g_m = 2 * I_DSS / |V_P|  (JFET transconductance at V_GS=0)
- g_m = 2 * I_D / V_ov  (MOSFET transconductance)
- g_m = I_C / V_T, V_T ≈ 26 mV  (BJT transconductance)
- A_v = -g_m * R_D  (voltage gain common-source / common-emitter)
- r_pi = beta / g_m  (BJT input resistance)
- C_in ≈ C_gs + C_gd * (1 + |A_v|)  (Miller effect input capacitance)
- Z_in = r_pi || (1/(j*omega*C_pi))  (BJT input impedance)

Frequency domain
- f_T = g_m / (2 * pi * C_iss)  (unity current-gain frequency FET)
- f_0 = 1 / (2 * pi * sqrt(L * C))  (LC resonance)
- BW = f_0 / Q  (resonant circuit bandwidth)
- f_-3dB = 1 / (2 * pi * R * C)  (RC low-pass)
- X_C = 1 / (2 * pi * f * C)  (capacitive reactance)
- X_L = 2 * pi * f * L  (inductive reactance)

Inductor design (loop antenna)
- L = mu_0 * r * [ ln(8r/a) - 2 ]  (circular loop inductance)
- Q = (2*pi*f*L) / R_loss  (quality factor)

Enhancement MOSFET (2N7000) Common-Source Amplifier
Circuit: Antenna wire (30cm) connected directly to gate. Gate connected to drain through resistor R_G = 1M ohm. Drain connected to +9V supply through R_D. Source grounded. No DC blocking capacitor is needed; the gate floats to the drain DC voltage via R_G.
Design calculations:
Choose V_DD = 9V. Let quiescent drain voltage V_D = 4.5V for maximum swing. Drain current I_D = (V_DD - V_D) / R_D. Pick I_D = 1mA, then R_D = (9 - 4.5) / 0.001 = 4500 ohm, use 4.7k standard.
Since gate current is zero, V_GS = V_D = 4.5V. Threshold voltage V_th typical = 2.1V, so overdrive voltage V_ov = V_GS - V_th = 4.5 - 2.1 = 2.4V. MOSFET saturation requires V_DS >= V_ov, and V_DS = 4.5V is satisfied.
Transconductance g_m = 2 * I_D / V_ov = 2 * 0.001 / 2.4 = 0.000833 S (0.833 mS).
Voltage gain A_v = -g_m * R_D = -0.000833 * 4700 = -3.9.
Antenna open-circuit voltage V_oc = E * h_eff = 0.05 V/m * 0.15 m = 0.0075 V RMS. Antenna capacitance C_ant ≈ 3 pF, 2N7000 input capacitance C_iss = 50 pF.
Gate voltage V_gate = V_oc * C_ant / (C_ant + C_iss) = 0.0075 * 3 / (3+50) = 0.0075 * 0.0566 = 0.000425 V RMS.
AC drain voltage v_drain = |A_v| * V_gate = 3.9 * 0.000425 = 0.00166 V RMS (1.66 mV RMS).
At 100 MHz, the large C_iss severely attenuates the signal; additionally the intrinsic f_T ≈ g_m/(2*pi*C_iss) = 0.000833/(2*pi*50e-12) ≈ 2.65 MHz, so the transistor cannot provide gain at 100 MHz. This circuit is not usable at VHF.

Depletion MOSFET (BF998) Common-Source Amplifier
Circuit: BF998 is a dual-gate MOSFET. Connect Gate1 to the antenna and also to ground through R_G1 = 100k ohm (provides DC path). Connect Gate2 to drain through R_G2 = 100k ohm. Source grounded. Drain to +12V supply through R_D. This arrangement sets Gate1 at 0V DC and Gate2 at the drain voltage. The device operates in depletion mode.
Design calculations:
V_DD = 12V. Typical IDSS at V_G2S = 4V is about 10 mA; with V_G2S = V_D, we estimate I_D ≈ 10 mA. Choose quiescent V_D = 6V. Then R_D = (12 - 6) / 0.01 = 600 ohm, use 560 ohm standard. Actual V_D = 12 - I_D * R_D ≈ 12 - 0.01*560 = 6.4V, giving V_G2S ≈ 6.4V (within safe limits).
Datasheet forward transconductance g_fs = 24 mS (typical at V_G2S = 4V, we use as approximation).
Voltage gain A_v = -g_fs * R_D = -0.024 * 560 = -13.4.
Input capacitance C_iss = 2.1 pF. Antenna: V_oc = 0.0075 V RMS, C_ant = 3 pF.
V_gate = V_oc * 3 / (3 + 2.1) = 0.0075 * 0.588 = 0.00441 V RMS (4.41 mV RMS).
AC drain voltage v_drain = |A_v| * V_gate = 13.4 * 0.00441 = 0.0591 V RMS (59.1 mV RMS).
The BF998 has f_T > 1 GHz, so it provides full gain at 100 MHz. This circuit is practical and gives a strong output.

JFET (J310) Common-Source Amplifier
Circuit: Gate to antenna, also to ground through R_G = 1M ohm. Source grounded. Drain to +9V supply through R_D. With V_GS = 0, the JFET conducts its saturation current IDSS.
Design calculations:
V_DD = 9V. For J310, typical IDSS = 15 mA, V_P = -2.5V.
To center the drain voltage, set R_D = V_DD / (2 * IDSS) = 9 / (2 * 0.015) = 300 ohm, use 330 ohm.
Quiescent drain voltage V_D = V_DD - IDSS * R_D = 9 - 0.015 * 330 = 4.05V.
Transconductance g_m0 = 2 * IDSS / |V_P| = 2 * 0.015 / 2.5 = 0.012 S (12 mS).
Voltage gain A_v = -g_m0 * R_D = -0.012 * 330 = -3.96.
Input capacitance C_iss = 2.5 pF. With antenna C_ant = 3 pF and V_oc = 0.0075 V RMS,
V_gate = 0.0075 * 3 / (3 + 2.5) = 0.0075 * 0.545 = 0.00409 V RMS (4.1 mV RMS).
AC drain voltage = 3.96 * 0.00409 = 0.0162 V RMS (16.2 mV RMS).
For 1 V/m field strength, V_oc = 0.15 V RMS, V_gate = 0.15 * 0.545 = 0.0818 V RMS, v_drain = 3.96 * 0.0818 = 0.324 V RMS (324 mV RMS). The amplifier remains linear because gate peak voltage (0.116 V) is far below the forward gate junction threshold (approx. 0.7 V). The J310's f_T ≈ 764 MHz ensures full gain at 100 MHz.

BJT (2N3904) Common-Emitter Amplifier with Collector-Base Feedback Bias
Circuit: Base directly connected to antenna wire (no coupling capacitor). Collector to +9V supply through R_C. Resistor R_B from collector to base. Emitter grounded. This feedback sets the DC operating point.
Design calculations:
V_CC = 9V. Choose I_C = 1 mA, V_CE = 4.5V for maximum swing.
R_C = (9 - 4.5) / 0.001 = 4500 ohm, use 4.7k.
Assume DC current gain beta = 100, so base current I_B = I_C / beta = 10 µA.
Base-emitter voltage V_BE = 0.7V, emitter grounded, so base voltage V_B = 0.7V.
Voltage across R_B = V_CE - V_BE = 4.5 - 0.7 = 3.8V.
Therefore R_B = 3.8 / (10e-6) = 380000 ohm, use 390k.
Small-signal transconductance g_m = I_C / V_T = 0.001 / 0.026 ≈ 38.5 mS.
Voltage gain A_v = -g_m * R_C = -0.0385 * 4700 = -181.
Input resistance r_pi = beta / g_m = 100 / 0.0385 ≈ 2600 ohm (2.6k).
At 100 MHz, BJT input capacitance C_pi (including Miller effect) becomes dominant. Miller capacitance C_miller = C_mu * (1 + |A_v|), with C_mu ≈ 4 pF (C_obo), giving about 4 * 182 ≈ 728 pF. Total input capacitance is very large. The base input impedance is therefore low, causing severe loading of the antenna (high impedance, reactive ~ -j530 ohm). The voltage at the base is drastically divided: V_base ≈ V_oc * |Z_in| / |Z_ant + Z_in|. With Z_in magnitude around 200 ohm at 100 MHz and Z_ant ≈ -j530 ohm, the division factor is roughly 200 / sqrt(530^2+200^2) ≈ 0.35, leading to V_base ≈ 0.0075 * 0.35 = 2.6 mV RMS. Then v_out = 181 * 0.0026 = 0.47 V RMS. However, this assumes the BJT still has gain at 100 MHz; 2N3904 f_T = 300 MHz, so gain is reduced. Practical gain will be lower, and circuit stability is poor due to the huge Miller capacitance. While the calculation suggests a large output, the input mismatch makes this circuit highly inefficient and prone to oscillation. The JFET and depletion MOSFET provide much better impedance matching to the capacitive antenna.

BJT Amplifier with Tuned LC Tank Input (Loop Antenna as Inductor)
Circuit description:
- Antenna: single‑turn circular loop, diameter 10 cm, made of 1 mm thick wire. This loop acts as the inductor L of the resonant tank.
- Tuning capacitor: a 2–15 pF variable capacitor (trimmer) is connected directly across the loop terminals.
- Transistor: BFP520 NPN SiGe HBT (fT ≈ 45 GHz) for excellent high‑frequency performance. A 2N3904 can also be used with reduced gain expectation.
- Biasing: emitter resistor R_E provides negative feedback to stabilise gain. Base voltage is set by a resistive divider R1, R2. Collector resistor R_C sets the output load. The tank (loop + C_tune) is connected between the base and ground; no coupling capacitor is needed because the base DC level is set by the divider and the loop has negligible DC resistance.
- DC blocking: the antenna is a closed loop with zero DC resistance, so the base will be pulled to the divider voltage. No series blocking capacitor is required.

Component values and operating point:
Chosen supply V_CC = 9 V. Desired collector current I_C ≈ 2.5 mA.
Emitter resistor R_E = 470 Ω. Emitter voltage V_E = I_E * R_E ≈ 2.5 mA * 470 Ω = 1.18 V (I_E ≈ I_C).
Base voltage V_B = V_E + V_BE = 1.18 V + 0.7 V = 1.88 V.
Voltage divider: R2 = 27 kΩ from base to ground. Current through divider I_D ≈ V_B / R2 = 1.88 V / 27 kΩ ≈ 70 µA.
R1 = (V_CC - V_B) / I_D = (9 V - 1.88 V) / 70 µA ≈ 102 kΩ; use 100 kΩ standard.
Collector resistor R_C = 2.2 kΩ.
Collector voltage V_C = V_CC - I_C * R_C = 9 V - 2.5 mA * 2.2 kΩ = 9 V - 5.5 V = 3.5 V. V_CE = V_C - V_E = 3.5 V - 1.18 V = 2.32 V; this is adequate for linear operation.
The emitter resistor R_E is left unbypassed to set a well‑defined voltage gain. Thus gain from base to collector is A_v = -R_C / R_E = -2200 / 470 ≈ -4.68.

Resonant tank calculations:
Loop inductance L (single turn, radius r = 0.05 m, wire radius a = 0.0005 m):
L = μ0 * r * [ ln(8r/a) - 2 ] = (4π×10^−7) * 0.05 * [ ln(8*0.05/0.0005) - 2 ]
  = 1.2566×10^−7 * [ ln(800) - 2 ] = 1.2566×10^−7 * (6.6846 - 2) = 1.2566×10^−7 * 4.6846 ≈ 5.89×10^−7 H = 0.589 µH.
(Note: a 10 cm loop gives a slightly higher inductance than earlier estimate; let's recompute carefully: ln(800)=6.6846, minus 2 = 4.6846; 1.2566e-7 * 0.05 = 6.283e-9, times 4.6846 = 2.94e-8 H = 0.294 µH. That was for 0.05m radius. My step above used 1.2566e-7 * 0.05 = 6.283e-9; times 4.6846 gives 2.94e-8 H = 0.294 µH. So my earlier value 0.294 µH is correct. I'll use 0.294 µH.)
Thus L = 0.294 µH.
Reactance at 100 MHz: X_L = 2πfL = 2π * 100×10^6 * 0.294×10^−6 = 184.7 Ω.
Unloaded Q of the loop is estimated at 100 (typical for a well‑constructed air‑core coil), giving resonant impedance R_p = Q * X_L = 100 * 184.7 ≈ 18.5 kΩ.
Required total capacitance for resonance at 100 MHz: C_tot = 1 / ((2πf)^2 * L) = 1 / ( (6.283×10^8)^2 * 0.294×10^−6 ) = 1 / (3.948×10^17 * 2.94×10^−7) = 1 / 1.16×10^11 = 8.62 pF.
The BFP520 has a very small input capacitance (C_be ≈ 0.2 pF, Miller effect is negligible because gain is low, so total C_in ≈ 1 pF). The trimmer capacitor is adjusted to bring the total parallel capacitance (C_trim + C_in + parasitic) to 8.6 pF. A 2–15 pF trimmer is ideal.

Signal voltage at base:
Open‑circuit induced voltage in the loop: the magnetic field B = μ0 * H, with H = E / 377 Ω = 0.05 V/m / 377 ≈ 1.33×10^−4 A/m. B = 4π×10^−7 * 1.33×10^−4 = 1.67×10^−10 T.
Loop area A = πr^2 = π * (0.05)^2 = 0.00785 m^2.
Induced EMF (RMS) V_oc = 2πf * N * A * B = 2π * 10^8 * 1 * 0.00785 * 1.67×10^−10 = 6.283×10^8 * 1.31×10^−12 ≈ 0.823 mV RMS (0.823 mV).
At resonance, the voltage across the tank is V_tank = V_oc * Q_loaded. The loaded Q is determined by the parallel combination of R_p (18.5 kΩ) and the input resistance of the BJT at the base. The BJT input resistance (base‑emitter) is approximately r_π = β / g_m. β ≈ 100, g_m = I_C / V_T = 0.0025 / 0.026 ≈ 96 mS, so r_π ≈ 100 / 0.096 ≈ 1.04 kΩ. The bias resistors R1, R2 appear in parallel with r_π. R1||R2 = 100k||27k ≈ 21.3 kΩ, so the net base AC impedance is approximately r_π = 1.04 kΩ (dominates). Thus R_p_loaded = R_p || r_π = 18.5k || 1.04k ≈ (18.5*1.04)/(19.54) ≈ 0.985 kΩ.
Loaded Q = R_p_loaded / X_L = 985 / 184.7 ≈ 5.33.
V_tank = V_oc * Q_loaded = 0.823 mV * 5.33 ≈ 4.39 mV RMS.
The voltage at the base is essentially V_tank because the coupling is direct (the tank is between base and ground).
Collector output voltage: v_out = |A_v| * V_base = 4.68 * 4.39 mV ≈ 20.5 mV RMS (29 mV peak).
For a 1 V/m field, all voltages scale linearly by a factor of 20 (since 1/0.05 = 20). V_oc = 16.46 mV, V_base = 87.8 mV, v_out = 411 mV RMS (581 mV peak). The circuit remains linear because the collector DC voltage is 3.5 V, allowing a peak swing up to about 3.5 V (worst case) without clipping. Thus the design handles 1 V/m with no problem.

Alternative BJT option: if a 2N3904 is used, its lower fT (300 MHz) reduces the effective gain at 100 MHz to roughly fT/f ≈ 3 for current gain, so voltage gain would be correspondingly smaller, but the tank circuit still provides selectivity and some amplification.

MOSFET (BF998) with Multi‑Turn Loop Antenna and Resonant Capacitor
Circuit description:
- Antenna: single‑turn loop, diameter 10 cm (same as above, L = 0.294 µH).
- Resonating capacitor: external capacitor C_ext (6.8 pF ceramic or trimmer) is placed in parallel with the loop, forming a resonant tank.
- BF998 dual‑gate depletion MOSFET. Gate1 (G1) is connected to the hot end of the tank. Gate2 (G2) is tied to the drain through a 100 kΩ resistor for DC feedback. Source grounded. Drain is connected to +12 V through R_D.
- A high‑value resistor R_G1 = 100 kΩ from G1 to ground provides a DC path; the gate DC voltage is 0 V (because no DC current flows in the loop). The MOSFET is in depletion mode, so it conducts at V_GS1 = 0 V.
- The input capacitance of the BF998 (C_iss = 2.1 pF) appears in parallel with the tank, so the external capacitor is chosen such that C_ext + C_iss = C_tot (8.6 pF). Thus C_ext ≈ 6.5 pF; use a 6.8 pF fixed capacitor with a small trimmer for fine tuning, or a 2–15 pF trimmer alone.

Component values and bias:
V_DD = 12 V. Typical IDSS around 10 mA with V_G2S ≈ V_D (after feedback). Choose drain resistor R_D = 220 Ω to limit gain and keep output swing within supply.
Quiescent drain current I_D ≈ 10 mA (this will be set by the device; the feedback resistor from drain to G2 ensures stable bias). Drain DC voltage V_D = V_DD - I_D * R_D = 12 - 0.01 * 220 = 9.8 V. This leaves limited headroom (only about 2.2 V to the positive rail) for positive output swing. To get a more centred bias, we can adjust R_D. Using R_D = 560 Ω as before gives V_D ≈ 12 - 0.01*560 = 6.4 V, better. However, gain becomes larger (g_fs * R_D = 0.024 * 560 = 13.4). We'll keep R_D = 560 Ω and later show that the output voltage is still within limits.
I'll set R_D = 560 Ω. Then V_D ≈ 12 - 0.01*560 = 6.4 V, fine.
G2 bias: a 100 kΩ resistor from drain to G2. G2 draws negligible DC current, so V_G2 ≈ V_D = 6.4 V. Datasheet allows V_G2S up to 8 V typically.
R_G1 = 100 kΩ from G1 to ground (provides DC path; G1 voltage is 0 V).

Small‑signal parameters:
Forward transconductance g_fs typical = 24 mS (at V_G2S ≈ 4 V; at 6.4 V it may be slightly higher, we'll use 24 mS).
Voltage gain A_v = -g_fs * R_D = -0.024 * 560 = -13.4.

Resonant tank and signal:
Loop inductance L = 0.294 µH, unloaded Q = 100, X_L = 184.7 Ω, R_p = 18.5 kΩ.
Total capacitance at resonance C_tot = 8.6 pF. C_iss = 2.1 pF, so external C_ext = 6.5 pF.
The MOSFET gate input impedance is purely capacitive (no resistive loading except for the 100 kΩ bias resistor, which is negligible). Therefore the loaded Q remains essentially the unloaded Q of the loop (Q ≈ 100), because the parallel resistive loading is only the very high R_p of the coil itself (18.5 kΩ) and the bias resistor does not shunt it significantly (100 kΩ || 18.5 kΩ ≈ 15.6 kΩ, Q_loaded ≈ 15.6k/184.7 ≈ 84). So we take Q_loaded ≈ 85.
Voltage across the tank at resonance: V_tank = V_oc * Q_loaded = 0.823 mV * 85 ≈ 70 mV RMS (99 mV peak). This voltage appears at G1.
Drain AC voltage: v_drain = |A_v| * V_tank = 13.4 * 70 mV = 938 mV RMS (1.33 V peak).
For a 1 V/m field, V_oc = 16.46 mV, V_tank = 16.46 mV * 85 ≈ 1.4 V RMS (1.98 V peak). Then v_drain = 13.4 * 1.4 V = 18.8 V RMS (26.6 V peak), which far exceeds the 12 V supply and would be severely clipped. Therefore for strong fields, the gain must be reduced. This can be done by lowering R_D (e.g., to 100 Ω, giving A_v = 2.4) and/or by adding a resistive load across the tank to reduce Q. A practical solution is to place a resistor of, say, 2.2 kΩ across the loop to set Q_loaded to about 2.2k/184.7 ≈ 11.9, then V_tank = 16.46 mV * 11.9 ≈ 196 mV, and with A_v=2.4, v_drain = 470 mV RMS, well within the supply. I'll mention this flexibility. For the primary design at 0.05 V/m, the high Q is acceptable.

JFET (J310) with Multi‑Turn Loop Antenna and Resonant Capacitor
Circuit description:
- Same loop antenna (L = 0.294 µH) with parallel capacitor to resonate at 100 MHz. External C_ext = 6.2 pF (since J310 C_iss = 2.5 pF, total required 8.6 pF, so 8.6 - 2.5 = 6.1 pF; use 6.2 pF standard).
- J310 JFET, source grounded, gate connected to the top of the tank. A 1 MΩ resistor from gate to ground provides DC path (gate DC voltage = 0 V). The JFET operates at V_GS = 0, with drain current I_DSS.
- Drain resistor R_D from drain to +9 V supply.
- For linear operation at 0.05 V/m, we choose R_D to centre the drain voltage and set gain.

Design calculations:
V_DD = 9 V. J310 typical I_DSS = 15 mA, V_P = -2.5 V.
To set V_D ≈ 4.5 V: R_D = (9 - 4.5) / 0.015 = 300 Ω; use 330 Ω standard. Then V_D = 9 - 0.015*330 = 4.05 V (as before).
Transconductance g_m0 = 2 * I_DSS / |V_P| = 2*0.015 / 2.5 = 0.012 S (12 mS).
Voltage gain A_v = -g_m0 * R_D = -0.012 * 330 = -3.96.

Tank and signal:
Loop: L=0.294 µH, Q_unloaded=100, X_L=184.7 Ω, R_p=18.5 kΩ. Gate bias resistor 1 MΩ has negligible effect. Input capacitance C_iss = 2.5 pF is absorbed into C_tot. Loaded Q ≈ unloaded Q (since no resistive loading except R_p and large R_G), Q_loaded ≈ 100 (a slight reduction due to R_G in parallel, 1MΩ || 18.5k ≈ 18.2k, Q ≈ 98.5). So we can use Q_loaded = 98.
V_oc = 0.823 mV RMS as before.
V_tank = V_oc * Q_loaded = 0.823 mV * 98 ≈ 80.7 mV RMS (114 mV peak).
V_gate = V_tank = 80.7 mV RMS.
Drain output: v_drain = |A_v| * V_gate = 3.96 * 80.7 mV ≈ 319 mV RMS (452 mV peak).
For a 1 V/m field, V_oc = 16.46 mV, V_tank = 16.46 mV * 98 ≈ 1.61 V RMS (2.28 V peak). Then v_drain = 3.96 * 1.61 = 6.38 V RMS (9.03 V peak). This will clip because the drain can only swing between 0 V and 9 V, and the quiescent drain is 4.05 V; a 9 V peak swing far exceeds the available headroom. Therefore for strong signals, the circuit must be desensitised. Adding a parallel resistor across the tank to lower Q, or reducing R_D (and thus gain) and rebiasing, can accommodate 1 V/m. For example, a 2.2 kΩ resistor across the coil gives Q_loaded ≈ 2.2k/184.7 = 11.9, V_tank = 16.46 mV * 11.9 = 196 mV, and with R_D = 100 Ω (and V_D recentered by using higher I_DSS device or adjusting supply), gain = 1.2, output = 235 mV RMS, well within limits.

Summary of equations used for these designs:
- Loop inductance: L = μ0 * r * [ ln(8r/a) - 2 ]
- Resonant frequency: f = 1 / (2π * sqrt(L*C))
- Capacitive reactance: X_L = 2πfL
- Quality factor: Q = R_p / X_L, R_p = Q_u * X_L
- Loaded Q: Q_L = R_p_loaded / X_L, where R_p_loaded = R_p || R_load
- Induced EMF in loop: V_oc = 2πf * N * A * B, with B = μ0 * E / 377
- Capacitive voltage divider (not needed here because of resonance)
- FET transconductance: g_m = 2*I_DSS/|V_P| (JFET) or given (MOSFET)
- Voltage gain: A_v = -g_m * R_D (common source) or -R_C/R_E (BJT with emitter degeneration)
- DC bias: V_D = V_DD - I_D*R_D; V_C = V_CC - I_C*R_C
- BJT base voltage divider: V_B = V_CC * R2/(R1+R2), I_D = V_B/R2, R1 = (V_CC - V_B)/I_D
- BJT emitter current: I_E = V_E / R_E, V_E = V_B - V_BE
- Output voltage: v_out = A_v * V_input

All these circuits are practical and can be built with standard components. The loop antenna provides excellent frequency selectivity and high signal voltage due to the Q multiplication, making it ideal for single‑frequency reception at 100 MHz.
