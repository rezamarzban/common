
## **Wanway G19S TCP Protocol**

### **1. Packet Structure**
[START][LEN][PROTO][DATA][CRC][END]
7878   XX   YY    ...   ZZZZ 0D0A


### **2. Protocol Types & ACK Responses**
| Proto | Type | ACK Response | Sequence Bytes |
|-------|------|--------------|----------------|
| `0x01` | Login | `7878050100SSCC0D0A` | `pkt[16:18]` |
| `0x13` | Heartbeat | `7878051300SSCC0D0A` | `pkt[7:9]` |

### **3. GPS Packet (0x22) Structure**
 `lat_bytes = pkt[11:15]` and `lon_bytes = pkt[15:19]`
Offset | Bytes | Field (Code Shows)
-------|-------|-------------------------
0-1    | 2     | Start (7878)
2      | 1     | Length (0x26 = 38 bytes)
3      | 1     | Protocol (0x22)
4-9    | 6     | DateTime (YY MM DD HH MM SS)
10     | 1     | GPS Info (satellites/fix)
11-14  | 4     | **Latitude** (signed int32) ← code: pkt[11:15]
15-18  | 4     | **Longitude** (signed int32) ← code: pkt[15:19]
19     | 1     | **Speed** (km/h) ← code: speed = pkt[19]
20+    | ...   | Other status bytes
last-4 | 2     | CRC16
last-2 | 2     | End (0D0A)


### **4. Coordinate Decoding Formula**
```python
lat_int = int.from_bytes(pkt[11:15], "big", signed=True)
lon_int = int.from_bytes(pkt[15:19], "big", signed=True)
latitude  = lat_int / 1_800_000.0  # Verified working
longitude = lon_int / 1_800_000.0  # Verified working
```

### **5. Speed Extraction**
```python
speed = pkt[19]  # Byte at offset 19 = speed in km/h
```
Speed is **1 byte** at offset 19, directly in km/h units.


### **6. Critical Implementation Notes**
1. **Sequence bytes position differs**:
   - Login (`0x01`): Sequence at bytes 16-17
   - Heartbeat (`0x13`): Sequence at bytes 7-8
2. **Must ACK every packet** - Device stops if no ACK
3. **CRC16-XMODEM** for ACK packets (polynomial 0x1021)
4. **All packets end with** `0x0D0A`


### **7. Complete Protocol Summary**
Login:    78 78 0D 01 [IMEI...] [SEQ] [CRC] 0D 0A
Heartbeat:78 78 0A 13 [SEQ...] [CRC] 0D 0A  
GPS:      78 78 26 22 [DateTime] [GPSinfo] [Lat4] [Lon4] [Speed1] [Status...] [CRC] 0D 0A

ACK all:  78 78 05 [Proto] 00 [SEQ] [CRC] 0D 0A
